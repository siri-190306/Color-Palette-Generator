# 🎨 Color Pop — Color Palette Generator

A fun, beginner-friendly web application that generates random HEX color palettes. Explore new colors, copy their HEX codes, and use them in your creative projects!

## ✨ Features

- Generate five random HEX colors.
- Display colors as interactive swatches.
- Copy any HEX code to the clipboard.
- Show a notification after copying.
- Responsive design for mobile and desktop.
- Colorful pastel-inspired interface.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Click **Generate New Palette** to explore colors.
7. Click a color card to copy its HEX code.
